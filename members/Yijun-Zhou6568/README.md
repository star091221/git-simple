# 我的 Git 学习笔记

###### **第一次 Git 实验总结**

1\. ‘git add’ 的作用是：把工作区中修改好的文件添加到暂存区，让Git追踪本次准备提交的改动。

2\. ‘git commit’ 的作用是：把暂存区里的改动保存到本地Git仓库，同时生成一条带描述的记录，只在本机保存。

3\. 本次实验中 ‘git restore notes.md’ 的作用是：丢弃工作区中对notes.md新增的临时文字修改，把文件恢复到上一次commit保存的版本。

4\. ‘commit’ 与 ‘push’ 的区别是：commit是把改动提交到本地仓库，仅保存在自己电脑；push是把本地仓库的提交记录上传到远程GitHub仓库并同步到云端。
