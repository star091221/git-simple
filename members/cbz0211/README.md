# git-simple
第一次git作业
1. `git add` 的作用是：把工作区的修改放入暂存区（staging area），告诉 Git 你准备把哪些文件的变化纳入下一次提交。

2. `git commit` 的作用是：把暂存区的内容正式提交到本地仓库的历史记录中，形成一条不可变的提交记录。

3. 本次实验中 `git restore notes.md` 的作用是：放弃工作区中对 notes.md 的未暂存修改，将其恢复到上一次提交时的内容，相当于撤销了那句临时追加的练习文字。

4. `commit` 与 `push` 的区别是：commit 只是把提交保存到本地仓库，其他人看不到；push 才把本地提交推送到远程仓库，让其他人可见。
